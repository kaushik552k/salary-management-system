# AI Tool Usage Log

This document captures how AI tools were used during the development of this assessment, as requested in the brief.

## Tools Used

- **Antigravity IDE (Google DeepMind)** — Agentic AI coding assistant used throughout

---

## Usage Patterns

### 1. Planning & Architecture
- Used AI to brainstorm trade-offs between SQLite vs PostgreSQL, Express vs Fastify, multi-currency vs single-currency approaches
- AI generated the initial project folder structure which was reviewed and approved before any code was written
- Requirements document was drafted with AI assistance and reviewed for completeness

### 2. Boilerplate & Scaffolding
- Backend `package.json`, `tsconfig.json`, and `jest.config.json` were generated by AI based on confirmed tech stack
- Prisma schema generated from the data model discussion
- Express app factory pattern (`app.ts` vs `index.ts`) suggested by AI to improve testability

### 3. Business Logic
- Employee service (filtering, pagination, soft delete, currency assignment) — drafted by AI, reviewed for correctness
- Analytics service (multi-currency normalization, histogram bucketing, grouping) — drafted by AI
- Seed script structure and weighted random distribution logic — drafted by AI

### 4. Tests
- Test structure and coverage targets discussed with AI
- Test cases (happy paths, edge cases, validation failures) generated by AI and reviewed
- Mock Prisma pattern in tests suggested by AI to avoid DB dependency in unit tests

### 5. Frontend
- Next.js App Router folder structure planned with AI
- Component hierarchy (layout → pages → components → hooks) designed collaboratively
- API client types (`lib/api.ts`) generated from backend schema

---

## What I Reviewed & Owned

Every piece of AI-generated code was:
1. **Read and understood** before being committed
2. **Reviewed for correctness** — especially the currency conversion math, pagination logic, and Zod validation schemas
3. **Tested** — all business logic is covered by tests that I reviewed and understand

The AI accelerated my velocity significantly, but all design decisions (soft delete, multi-currency, server-side pagination, service/route separation) were made by me and are ones I can defend.

---

## Honest Trade-offs

- The AI occasionally produced verbose code that I simplified
- Some test mocking patterns were suggested by AI and adapted to the actual Prisma client interface
- The seed script's weighted distribution logic was AI-generated but I verified the math manually (weights sum to 1.0, level weights form a realistic pyramid)
